# Sprint 7: Reviewer Trial And UI De-Dev Pass

## Status

Parked draft for review. Do not start Sprint 7 implementation until Sprint 5 report-intelligence work is stable enough to test against a real reviewer workflow.

This file and the linked subunit files are root-level planning notes for human review. Move them into the sprint docs area only after review.

## Purpose

Shift Review Assist from a builder-facing/debug-friendly app into a reviewer-facing workflow a real reviewer could actually use.

This sprint is not about deep backend capability. The goal is to make the app calmer, clearer, and usable by a real reviewer starting from a fresh project.

## Explicit Non-Goals

Do not use this sprint for:

- Broad source acquisition.
- Full GPT rollout.
- Production auth or deployment.
- PDF export.
- Advanced audit UI.
- Perfect cartography.
- Major report policy redesign.
- Changing the deliverable matrix unless testing exposes a true blocker.

## Sprint 7 Success Statement

A reviewer can start from a fresh project file, run the workflow, understand what Review Assist found, make decisions, and export a compact review package without needing to understand the internal warehouse machinery.
